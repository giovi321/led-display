The one-off configuration that lives behind the advanced-mode toggle:

- [Advanced mode](advanced-mode/): what the toggle reveals and why it exists
- [Arrangement editor](arrangement-editor/): describe the physical panel layout graphically
- [Light sensor](light-sensor/): let the room set the brightness
- [API key and web UI login](api-key/): a header key for scripts, a browser login for people, both optional
- [OTA updates](ota-updates/): browser upload or update-from-URL, with rollback
- [Backup and restore](backup-restore/): the whole configuration as one JSON file
- [WireGuard](wireguard/): remote access without port forwarding
