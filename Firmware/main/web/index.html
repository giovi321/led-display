Test patterns

Step strip walks the physical chain so you can see where index 0, 1, 2... land. Corners lights logical (0,0)=red, (W-1,0)=green, (0,H-1)=blue, (W-1,H-1)=yellow using the active mapping. Stop puts the normal content back.

Brightness cap

The cap limits maximum brightness to protect the power supply. The brightness slider and API requests cannot exceed it.

Light sensor

Optional. An analog light sensor - an LDR voltage divider or an analog lux module - can set the brightness for you as the room changes.

This device's private key
Server public key

0.0.0.0/0 sends every packet through the tunnel, including the replies to whoever is reading this page. If your computer is not on the same subnet as the display, you will lose access to it until you power-cycle and switch this off. For reaching the display remotely, the tunnel's own subnet is enough.

Connection details

The public key is only needed if you write the server's peer entry by hand. A server that generates the client configuration for you - UniFi, and most router and VPN provider interfaces - derives it itself and never asks for it.

API key

When a key is set, every POST must send it as X-Api-Key. Leave unset on a trusted network.

Base topic

MQTT commands are not gated by the API key - the broker's own authentication is the boundary. Push values to <base>/value/set to feed the display, same formatting as the value endpoint below.

Device name

Letters, digits and hyphens, up to 24 characters. Leave it empty for the defaults. Webhooks use a new name straight away; the network hostname follows on the next DHCP renewal or reboot, and the setup network is renamed the next time it appears - so saving will not disconnect you.
