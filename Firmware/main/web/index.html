Step strip walks the physical chain so you can see where index 0, 1, 2... land. Corners lights logical (0,0)=red, (W-1,0)=green, (0,H-1)=blue, (W-1,H-1)=yellow using the active mapping. Stop puts the normal content back.

Brightness cap

The cap limits maximum brightness to protect the power supply. The brightness slider and API requests cannot exceed it. It scales colour without knowing what the frame will draw; the power budget below is the calculated version.

Power budget

The device adds up the colour values in every frame it sends and prices them, so the Appearance tab can tell you what a brightness will draw before you apply it. Switch the limiter on and it also acts: a frame over budget goes out dimmer instead of tripping the supply.

Off by default. While it is off the figures are reported and nothing is changed, which is what you want until the numbers below match what your meter says.

Calibration

Two constants describe your panels. The defaults are the WS2812B datasheet figures, which over-predict on most panels sold - the safe direction, because the alternative is a limiter that lets the supply trip. To pin them down: lower the brightness, run Fill under Diagnostics (it lights every LED at a fixed colour), and compare the estimated draw on the Appearance tab against a meter in the supply lead. Scale the per-channel figure by whatever ratio you find. The power budget page has the version that separates the two constants properly.

The idle figure is the one people forget: a WS2812B draws about a milliamp with every channel off, so a 1024-LED chain wants roughly 1000 mA before it shows anything at all.

Web UI login

The browser asks once and remembers it for the session. This covers the whole interface, pages and API alike, not just the buttons that change something. The API key on the Integrations tab is separate and keeps working for scripts.

Sent over plain HTTP: this keeps casual visitors on your network out, and does not protect against anyone able to watch the traffic. It is not applied on the setup network, so if you lose the password, stopping the device from reaching your WiFi brings that network back after 30 minutes and lets you in.

Device name

Letters, digits and hyphens, up to 24 characters. Leave it empty for the defaults. Webhooks use a new name straight away; the network hostname follows on the next DHCP renewal or reboot, and the setup network is renamed the next time it appears - so saving will not disconnect you.
